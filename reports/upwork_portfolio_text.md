# Upwork Portfolio Entry — Project 1

## Title
Retail Sales Analysis | Python · SQL · PostgreSQL · Data Visualization

## Description (paste this in Upwork)
---
Analyzed 9,994 retail transactions across 4 years to uncover hidden profit leaks and growth opportunities for a US-based superstore.

**What I did:**
- Cleaned and structured raw CSV data using Python (Pandas) — handled encoding, date parsing, and null values
- Loaded data into PostgreSQL and wrote 8 analytical SQL queries (YoY growth, segment analysis, discount risk analysis)
- Built 4 professional visualizations: category performance, regional comparison, monthly trend, and discount-profit correlation
- Delivered 6 concrete business insights with clear revenue and cost implications

**Key findings delivered:**
- Identified that 18% of orders were generating losses due to aggressive discounting
- Pinpointed Furniture as the lowest-margin category (2.5%) vs Technology (17.4%)
- Discovered strong negative correlation (-0.22) between discounts ≥ 40% and profitability

**Tools used:** Python · Pandas · PostgreSQL · Matplotlib · Seaborn · Jupyter Notebook
